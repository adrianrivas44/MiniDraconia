# Community roadmap

This is a list of improvement areas, not a delivery schedule or a claim that the features already exist.

## First release foundation
- Reliable clean-machine Windows startup and clear error reporting.
- Versioned source/build provenance and complete dependency notices.
- Reproducible tests that cover both normal startup and scripted selftest.
- Privacy/asset review, human visual review and individual audio acceptance.

## Desktop quality
- Scaling, multi-monitor positioning and accessibility.
- Native falling/dragging behavior and animation-transition polish.
- More varied, context-appropriate English offline reactions.
- Clear onboarding and recoverable preferences.

## Connect your own model — future, not implemented

Explore optional Anthropic/Claude and xAI connectors while keeping the default offline. Start with a design covering credential storage, consent, costs, timeouts, supported APIs and data leaving the machine. A paid chat subscription is not proof of API entitlement. Never bundle a maintainer's token or route users through an undocumented shared account.

## Character contributions

Use the soul and visual guide as references, not as a license to import unrelated personal prompts or copyrighted official material. Preserve the adult fan-created identity, honest capability boundaries and user consent. Model-based character acceptance tests remain proposed until a real connector/model is tested.
