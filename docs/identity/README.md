# Draconia — character and visual reference

These are **the MiniDraconia product's character documents**, not the private configuration of a deployed assistant. The maintainer authorized preparing them for sharing. They do not include an active account, personal conversations, credentials or access permissions.

## Included references

- `SOUL.es.md`: full Spanish v6 character identity, retained from its original text.
- `SOUL-compact.es.md`: compact Spanish v6 identity.
- `SOUL.en.md` and `SOUL-compact.en.md`: the English full/compact product references.
- `Manual-de-identidad-Draconia-v5.pdf`: existing Spanish visual manual, preserved rather than redesigned.

**Versions refer to different layers.** The desktop candidate is1.0.0-rc.1; the character text is v6 and the existing manual is v5. The manual includes an earlier soul excerpt. The standalone v6 documents are the newer character-text reference; no PDF page has been silently rewritten to hide that difference.

## What a soul does—and does not do

A soul describes voice, fictional identity and behavioral intent. In the current desktop app, reactions are scripted. The document does not install an LLM, enable general conversation, add memories, access a camera/microphone or grant tool permissions. Conversation acceptance cases are design examples until exercised against an actual model integration.

Draconia is explicitly an adult fan-created reinterpretation inspired by Draco Malfoy, not official franchise material. Fictional relationship/roleplay instructions do not authorize real-world actions or override consent, safety or honest capability reporting.

## Contributing without identity drift

Keep the established appearance and expressive character. Propose a specific dialogue/art change with its rationale and source. Avoid automatic rewrites into a generic assistant, repeated insults or escalating intimacy. Do not substitute another person's private soul or personal material.

The original PDF labels its provenance as private-use fan material. Including it in a local release candidate is not a statement that all underlying character/art rights have been cleared for public redistribution. Resolve [rights-review](../RIGHTS-REVIEW.md) before publishing.
